# 2026-01-15 1월 정기회의

가상 과제의 협업처 정기회의 예시. 녹음은 본회의(external)와 회의 후 교수님 피드백(internal) 두 개. 녹음 파일은 용량 문제로 넣지 않음.

## 계보
| 단계 | 만든 주체 | 입력 | 시점 |
|---|---|---|---|
| 0_source | 사용자 (STT 결과, 메모) | 회의 녹음·STT 서비스 | 2026-01-15 |
| 1_extract | 스크립트 (`transcribe_audio.py` large-v3) | 0_source 녹음 | 2026-01-15 |
| 2_transcript | 에이전트 전사 절차 + 사용자 확인 2건 | 0_source, 1_extract, 용어사전 | 2026-01-15 |
| 3_minutes | 에이전트 회의록 절차 (종합본, 공유본 md·pdf, 메일 본문) | 2_transcript, 메모 | 2026-01-15 |

## 비고
- 기준 레포 "없음" 설정이라 코드 대조 점검은 건너뜀
- 종합본 3.3의 `[? internal 00:37 …]`은 전사 단계에서 답하지 않은 확인 표시. 내부 묶음 안이라 공유본 생성은 막지 않음
