# 예시

가상 과제의 회의 하나를 원본부터 메일 본문까지 모두 처리한 결과. 인물·회사·수치는 모두 지어낸 것.
에이전트는 결과물의 형식과 밀도를 이 예시에 맞춘다. 용어·화자 판단의 근거로는 쓰지 않는다.

## 이 예시가 가정한 설정
- **개인 설정 (`_config/me.md`)**
  이름 홍길동. 말투 규칙은 첫 줄 "{호칭}께.", 인사 "안녕하십니까 {직함}, OO대학교 김교수 교수님 연구실 석사과정 홍길동입니다.", 맺음 "감사합니다." 다음 줄 "홍길동 드림"
- **과제 설정 (`_config/project.md`)**  
  협업처 가나전자(약칭 가나), 공유본·메일 본문 사용, 메일 제목 머리 `[OO Lab]`, 기준 레포 없음
- **화자 명단 (`_glossary/speakers.md`)**  
  연구원1 홍길동, 교수님 김교수, 책임연구원1 이책임(가나전자), 가나 연구원1 최연구(가나전자)
- **용어사전 (`_glossary/terms.md`)**  
  MPC(오인식 "엠피씨"), 칠러, 가나전자

## 보면 좋은 곳
| 파일 | 볼 것 |
|---|---|
| `0_source/external_stt.txt` | STT 결과 그대로 (화자는 "참석자 N") |
| `2_transcript/external.md` | 화자 실명, 용어사전 표기(엠피씨 → MPC), 사용자 확인으로 정한 수치(35도) |
| `2_transcript/transcript_log.md` | 두 엔진이 갈린 곳, 메모 분류와 공유본 포함 판정 |
| `3_minutes/…_종합본.md` | `(내부)` 표시 세 가지(제목, 목록, 표 머리 칸), 남은 확인 표시의 형식 |
| `3_minutes/…_공유본.md` | 종합본에서 내부 내용이 빠진 결과 (`make_shared.py` 생성) |
| `3_minutes/…_메일 본문.md` | 공유본 3.2를 확인 요청 목록으로 옮긴 메일 |
